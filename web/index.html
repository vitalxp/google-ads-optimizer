GAQL — Google Ads Query Language

            

              Run read-only SELECT queries against the current account
              (same idea as MCP run_gaql). Mutations (pause, bids, RSA)
              are not done here — use AI Assistant / Optimize.
            

            
    
              
  • FROM resource: campaign, keyword_view, search_term_view, ad_group_ad…
    • 
              
  • metrics.* usually need a date range: segments.date DURING LAST_7_DAYS (or LAST_30_DAYS).
    • 
              
  • Money fields are micros (cost_micros / 1_000_000 = account currency).
    • 
              
  • Errors often mean incompatible fields in one SELECT (e.g. budget + keyword_view).
