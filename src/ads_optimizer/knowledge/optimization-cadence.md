# Цикл ведения (ops)

## Ежедневно (5–15 мин) при активном спенде

- Аномалии: spend spike, 0 clicks, disapproved ads.
- Быстрый взгляд на search terms при Broad.

## 2–3 раза в неделю

- Search terms → negatives / новые Exact.
- Проверка бюджета (limited by budget на прибыльных кампаниях).
- Статус объявлений и policy.

## Еженедельно

- CPA/ROAS vs цель по кампаниям и группам.
- Ключи/ads с высоким spend и 0 конверсий за значимый объём кликов → пауза или переработка.
- QS/landing проблемы на money terms.
- Согласование крупных изменений с владельцем.

## Ежемесячно

- Структура: новые кластеры, склейка мёртвых групп.
- Пересмотр tCPA/tROAS (±15–20% макс. за шаг).
- Аудит пересечений Brand / Non-brand / PMax.
- Креативный refresh.

## Период обучения — не трогать пачкой

После смены bidding / крупного бюджета / состава конверсий: **избегать** одновременных правок ключей, объявлений, гео, сетей 3–7+ дней (пока стабилизируется).

## Принцип агента

1. KB (методика) → 2. live tools (цифры) → 3. preview mutate → 4. confirm → 5. apply.
Не предлагать 10 правок сразу; приоритизировать critical waste и tracking.
