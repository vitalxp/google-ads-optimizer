# Quality Score и лендинг

## Три рычага QS

1. **Expected CTR** — релевантность объявления запросу, сильные RSA, минусы мусора.
2. **Ad relevance** — тема группы = ключи = headlines.
3. **Landing page experience** — скорость, mobile, соответствие контента запросу, прозрачность, лёгкая конверсия.

Низкий QS → выше CPC. Лечится структурой и лендингом сильнее, чем «подкрутить ставку».

## Практика

- Money Exact с плохим QS → проверить URL и message match, не только ставку.
- Отдельные лендинги под кластеры лучше одного «универсального» сайта.
- Core Web Vitals / медленный mobile бьют и CR, и QS.

## Когда агент эскалирует человеку

Нужны правки сайта/оффера/цены — агент фиксирует гипотезу и не имитирует рост CR ставками.
